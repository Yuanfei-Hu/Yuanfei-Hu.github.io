Eye movements and episodic memory

What can patterns of visual sampling tell us about memory formation and retrieval?

Eye tracking
Episodic memory
Human behaviour
Computational analysis
Python · MATLAB · R

Context

This independent study examined the relationship between eye movements and episodic memory in human recall. It introduced me to the practical problem of connecting behavioural measurements with latent cognitive processes.

Approach

I worked with eye-tracking and behavioural data, using computational analyses to examine patterns of visual sampling during memory tasks.

Research significance

The project shaped my later interest in representations that evolve over time, and in the care needed when moving from an observable behavioural pattern to a mechanistic interpretation.
